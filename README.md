## Built with teams

### ROBERP · Frontend & backend

A **modular ERP for France’s social and care sector**. [ROBERP’s official website](https://roberp.fr/) presents administration, HR, activity tracking, quality, finance and governance in one platform. Organization-specific configuration and data scope support the different teams using the application.

I contribute to **React/Apollo interfaces and Django/GraphQL business logic** — including roles and permissions, document templates, task workflows and responsive UI improvements.

<p align="center"><a href="https://minhhieu04.github.io/#project-roberp"><img src="https://raw.githubusercontent.com/minhhieu04/minhhieu04/main/assets/roberp-product.svg" width="660" alt="ROBERP planning and company-switching illustration. Fictional interface, not a product screenshot." /></a></p>

[Explore the case study →](https://minhhieu04.github.io/#project-roberp) · [Official ROBERP website →](https://roberp.fr/)

**Also in my portfolio:** [GL Lifestyle+](https://minhhieu04.github.io/#project-gl), Gamuda Land’s app for buyers and residents, and [GDOS](https://minhhieu04.github.io/#project-gdos), property defect and handover workflows. My contribution to these products is backend-focused. Private source and customer data stay private.
